# History
From the beginning of learning linux at the start of 2025, to August 2026. I had started and learnt linux from scratch using CachyOS, which is a optimized variant of Arch using a modified kernel of its own. For the next year and a half, I never had any issues with the operating system itself unless it resulted directly from an action of my own. Due to the fact that I was learning some parts with the use of Artificial Intelligence (Preferably Gemini), some commands were outdated, irrelevant, or clashed with other existing packages which resulted in my crashes. I knew that from the start, and stopped when I had what I needed. Most issues occured when I reinstalled my system, either because I simply wanted to start from scratch, or I was dissatisfied with the way things had become. But while that is true, I always went back to CachyOS. That was until August. It was a regular week, updating my packages on the Monday like usual, not experiencing any issues for the past while, giving me a false sense of protecting, especially since I hadn't downloaded any new packages in around 2-4 weeks, and more true that I hadn't tweaked with any files that directly affected the operating system. But after updating my packges with sudo pacman -Syu, I restarted like usual to finalize the update, then for the first time, it had properly failed me. As I restarted my system, it went into emergency kernel mode, which I didn't mind, as it did that on occassion without me knowing why nor me caring as it tended to work after another restart, but after my second restart, it went to the same emergency mode, but this time, I was locked out. I still don't know why, nor did I do the deeper level of research to find out why, but the emergency mode wouldn't accept any keyboard inputs, thus trapping me from entering the debug terminal. And since it was my first real crash, I decided to finally 'distro-hop', so I decided to try out Fedora.

# Fedora
Fedora is a distribution that I've heard a decent amount of, seeing window leavers lean towards it like switch'n'click for example. I made the assumption that it is a easy to use distribution that provides a close enough feel for windows users to be comfortable using without forfeiting too many habits. After using it for a month, though using niri rather than the provided desktop environment, I can agree that it is very easy to get into without much hassle. Though to be completely honest, it felt similar to CachyOS, especially with the frame rates in the video games that I play, give or take 5-10%. But while the frame rates are similar, I can personally say that I did feel more inconsistencies while using Fedora, maybe the kernel differences were those, or it was simply placebo. All in all, Fedora is a fine distribution that I can recommend to anyone switching to learn Linux. But that is that.

# Verdict
After trialling for around a month, I decided that I just preferred CachyOS more than Fedora. Like I said, it's just preference.

# Current
As I spent the greater part of 2 years learning via CachyOS, I had become accustomed to the commands of Arch, and me being lazy, I simply didn't want to relearn the muscle memory I had built.  And so, I switched back to CachyOS... or so I tried. As I tried to reinstall CachyOS, the installer ran into trouble reformatting the SSD it was installing into. I tried reformatting the drive via windows before running the installer, nuking the partition with gparted, but still, nothing. Skill Issue 100%,  but hey, that's life. So I decided to try another thing. Arch. Since I was already using an Arch-Based distribution, I felt that it seemed right to try the raw form of it. Honestly having done a sin not using it several months earlier but whatever. People say that Arch is the hardest distribution to use/learn/install, but with the relatively new archinstall command, it was honestly really easy, while more interactive since it was cli based rather than the preferred GUI installer, it took the same amount of time to get into the desktop. Through archinstall, you could still pick between the four kinds of arch kernels, multiple types of desktop environments, no desktop environment or a minimal install. I opted with the stock kernel with the intention of switching to the CachyOS kernel but as the day progressed, I decided that it was unnessary and a waste of time to do. And like previously mentioned, I went with niri as my desktop environment. It is by far my favourite DE of all time. It just does everything I need, I love the tiling and scrolling aspects and it just feels so fluid.
